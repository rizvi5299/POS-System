# POSSystem

A Windows Forms Point of Sale (POS) application built using VB.NET and .NET 8.  
The system connects to a Microsoft Access database to manage products and sales transactions.
Great for small busineeses who would like to keep track of sales and inventory at checkout.
Microsoft Access database file is included with saved convenient queries.
## Features
- Desktop POS application using WinForms
- Product and sales transaction handling
- Microsoft Access database integration
- Simple UI designed for small-scale or educational use

## Tech Stack
- VB.NET
- .NET 8 (Windows Desktop)
- Windows Forms
- Microsoft Access

## Requirements
- Windows
- .NET 8 Desktop Runtime
- Microsoft Access Database Engine (ACE OLEDB)


## Running the Project
1. Clone the repository
2. Open the solution file in Visual Studio
3. Restore any dependencies if prompted
4. Build and run the application

## Notes
This project is intended for learning and demonstration purposes, focusing on desktop application development and database connectivity using VB.NET.
